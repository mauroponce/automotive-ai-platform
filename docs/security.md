# Security

Keep OpenAI, PostgreSQL, Auth.js, and S3 credentials server-only. Private S3 storage, signed URLs, MIME/size/dimension checks, checksum capture, API-key hashing, server-side budgets, organization-scoped Prisma queries, and Auth.js sessions are required before real asset intake. PostgreSQL is private to Compose in production. Never claim prompting guarantees vehicle fidelity.
