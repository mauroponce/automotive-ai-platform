# Deprecated local basic edit laboratory

The deterministic showroom-composition experiment is not part of Basic V1 and is not a customer workflow. It remains in the repository only as a historical, super-admin evaluation artifact while the advanced generative editing flow is designed.

Use [Local Basic V1: plate blur](./local-basic-plate-blur.md) for the supported local workflow. It supports one image at a time, local license-plate detection with mandatory manual review, strong blur, private local storage, and JPEG download.
