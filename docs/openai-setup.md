# OpenAI setup

Set `OPENAI_API_KEY` only in the `web`/`worker` server environment and set `APP_DEMO_MODE=false` only after authorization to incur charges. The worker consumes persistent pg-boss jobs and the provider uses the official Image Edit endpoint. The requested names `gpt-image-2.5-sunburst`, `gpt-image-2.5-flare`, and `gpt-image-2` remain configurable registry entries; availability and parameter support must be verified against the account before a real run. Never retry an uncertain paid request automatically.
