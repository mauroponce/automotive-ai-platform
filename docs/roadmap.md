# Roadmap

## Consolidated scope

Free: one photo, editable ONNX suggestions and Canvas blur entirely in the browser. Paid: advanced generative editing through OpenAI, private storage, durable batches, economic authorization and human review. Local server engines and laboratories are retired.

## Next sprint

1. Resolve weight redistribution/commercial licensing before public commercial launch. Validate detector accuracy on authorized Argentine/Mercosur examples.
2. Implement an organization prepaid credit ledger: verified purchases, reservations, consumption per final image, refunds and movement history. No mandatory subscription. Validate the tentative US$0.50 price against observed total costs first.
3. Define purchase verification and refund policies before implementing Mercado Pago. The payment integration was intentionally excluded from consolidation.
4. Validate Google OAuth with configured staging credentials and conduct one explicitly authorized paid OpenAI pilot. Measure fidelity, failed/retried images, costs and support effort; never call simulated results real quality evidence.
5. Add alerts and operator recovery for uncertain submissions and exhausted reconciliation retries. Build administrative backends only for demonstrated operational needs; existing placeholders remain marked pending.
6. Approve and execute a separate historical laboratory data retirement migration after backup/restore and retention review. No reset or destructive migration in this sprint.

Public API keys, enterprise integrations, subscriptions, local editing engines and new laboratories are outside the active MVP.
